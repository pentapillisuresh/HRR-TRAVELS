# HRR Travels — Premium Car Rental Website

Customer-facing React + Vite + JSX + Tailwind CSS website.

## Included screens
- Home
- Cars listing
- Car details
- Booking step 1: Rental details
- Booking step 2: Customer details
- Booking step 3: Documents
- Booking step 4: Booking summary
- Payment
- Booking confirmation
- My bookings
- Login
- Register
- How it works
- About
- Contact
- FAQ
- 404

## Run
```bash
npm install
npm run dev
```

## Notes
- This is frontend-only.
- Car data is currently in `src/data/cars.js`.
- Booking state is held in React context.
- Payment, authentication, document upload and booking persistence are UI flows only until a real backend/API is connected.
- Replace the image URLs with your own licensed vehicle photos for production.
